# Kalaa

Shashank's design system: one calm, professional look for every app. *Kalā*: art and craft in Hindi, a phase of the
moon in Sanskrit.

- `@kalaa/tokens`: design tokens (CSS custom properties, JSON, TypeScript), light and dark themes.
- `@kalaa/react`: accessible React components on headless primitives, styled with Kalaa tokens.
- `apps/catalog-admin`: sample app built only with Kalaa.

Status: planning (P0 next). Plan and decisions: [docs/PLAN.md](docs/PLAN.md). Private until a deliberate public release.
