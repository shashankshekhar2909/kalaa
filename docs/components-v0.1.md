# Kalaa v0.1 components: spec (P1, 2026-11-19)

Visual rules: docs/foundations-draft.md (copy rules, layout, component intent) with token names from docs/tokens.md
(`--kalaa-*`). Direction: calm product tool, one accent, sentence case, status colours only for status.

## Conventions (all components)

- Folder per component: `packages/react/src/components/<Name>/` with `<Name>.tsx`, `<Name>.css`, `<Name>.stories.tsx`,
  `<Name>.test.tsx`. Export from the lane's barrel (`src/layout.ts` or `src/forms.ts`), types included.
- React 19: `ref` is a normal prop (no forwardRef). Spread remaining native props onto the root element; accept
  `className` and merge with `cx()` from `src/util.ts`. Typed props, no `any`, named exports only.
- CSS: plain CSS, every class starts with `kl-` (BEM-ish: `kl-button`, `kl-button--primary`, `kl-button__icon`),
  colours/sizes only from `var(--kalaa-*)` tokens (enforced by `node scripts/css.mjs --check`). No global element
  selectors. States via `:hover`, `:focus-visible`, `[disabled]`, `[aria-*]`, and Base UI `data-*` attributes.
  Focus: `outline: 2px solid var(--kalaa-focus); outline-offset: 2px` on `:focus-visible`.
  Motion: `var(--kalaa-duration-*)` / easing tokens only (they drop to 0 under reduced motion).
- Use Base UI 1.9 (`@base-ui/react/<part>`) for anything with behaviour: dialog, tabs, select, checkbox, switch,
  field, progress, button where useful. Read its types in `node_modules/@base-ui/react/<part>/*.d.ts` (no network).
- Stories (CSF3, title `Components/<Name>`): one story per meaningful variant plus a "States" story (disabled,
  error, loading, long text). Use realistic catalog-admin copy (products, imports, review), sentence case. Stories must
  pass axe (WCAG 2.2 AA) in light and dark; give every control an accessible name.
- Tests (Vitest + Testing Library, `*.test.tsx`): roles and names, keyboard behaviour (Tab, Enter/Space, Escape,
  arrows where relevant), disabled/aria states, `className` and ref pass-through.

| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
