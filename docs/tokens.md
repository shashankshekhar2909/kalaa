# Tokens

Palette primitives are DTCG colour ramps generated by `packages/tokens/scripts/ramps.mjs`. Anchors are preserved, and the remaining steps are interpolated in OKLCH. Semantic roles in `src/roles.json` map each accent and mode to palette steps; components should use roles, not primitives. Other foundations live in `src/foundation.json`. Style Dictionary resolves the aliases during the build, which emits CSS, resolved JSON, and JavaScript with TypeScript declarations. The contrast script checks the resolved role pairs.

Import `@kalaa/tokens/fonts.css` and `@kalaa/tokens/tokens.css`. Set `data-accent="geru"` or `data-accent="mayur"` on `html`; omit it for Neel. Set `data-theme="light"` or `data-theme="dark"` to override the system preference; omit it to follow the system. Reduced motion sets duration tokens to zero.

To add an accent, add its anchors and a biased neutral ramp to `scripts/ramps.mjs`, extend the accent list and role mapping in `build.mjs`, and add its toolbar option. Run the build and inspect the contrast table in both modes. Never adjust an agreed anchor silently to make a check pass.

## Shape

Kalaa is square by default: `radius-sm`, `radius-md`, `radius-lg` and `radius-pill` are all `0`. Set `data-shape="soft"` on `html` (or any wrapper) to restore 6px, 8px, 12px and 999px. Shapes live in `src/shapes.json` (DTCG); the first entry is the default and each other entry becomes a `:root[data-shape="…"]` block, and `shapes` is exported from the package like `accents`. Components must use these tokens and never hard-code a radius. Use `radius-pill` for track-like shapes (Switch, ProgressBar) and `radius-full` (always 999px) only for true circles such as the Button spinner. Do not use a radius token as a size.

## Nested themes

Accent, theme and shape selectors are plain attributes with the same specificity as `:root`, so they also work on nested wrappers: `<div data-accent="geru" data-theme="dark" data-shape="soft">` re-themes its subtree, and `data-shape="square"` or `data-accent="neel"` resets back inside such a wrapper. A wrapper that changes the theme should also set `data-accent` unless it is Neel.
